Back in May I wrote about my [vibe coding setup](/blog/vibe-coding-setup-may-2026-my-go-to-stack/). At the time it was VS Code with the OpenChamber plugin running OpenCode, DeepSeek Flash doing the thinking, and me steering the changes step by step. That was my daily driver for a while and it worked well.

Then I tried Hermes Agent. I wasn't planning on dropping my old editor, but the more I used Hermes, the less I opened VS Code. After a few weeks I realized I hadn't really needed to open it at all.

## What changed

VS Code with an AI plugin still feels like sitting inside an editor where you prompt, check the diff, and steer every small step yourself.

Hermes ties together my tools, skills, memory of how I work, recent chats, and active projects in one place. Because all that context is already loaded, I don't have to re-explain my setup or preferences every time I start something new.

That is what let me step back a bit. Scaffolding a new project used to mean a long session of prompting, checking, and nudging the model back on track. Now I spend most of my time on planning, reviewing, and scoping the idea while the agents handle the build work.

## My team of agents

Right now I split the work across four agents:

- My primary agent handles planning, reviews, and handoffs between projects.
- Hoshi handles social planning and content drafts.
- Josh is my coding agent that takes a plan and builds out the code.
- Compass handles research.

The biggest time saver is that they remember how I work. Over time they pick up how I like things structured, how I write, and what I usually ask for, so I have to spell out less each week.

I originally expected Hermes to just sit alongside VS Code as another helper. Instead it ended up replacing most of what I used the editor for. VS Code is still installed and ready when I want it, I just haven't needed it lately.
